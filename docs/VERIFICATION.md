## 발견하고 수정한 문제

1. **모바일 클릭 좌표 오류:** 레일의 최소 콘텐츠 폭이 grid를 늘리던 문제를 `minmax(0, 1fr)`와 `min-width: 0`으로 수정했다.
2. **무한 휴식:** 허기 상한에서 회복이 아사 피해를 앞질러 무한 회복할 수 있던 경로에 `prison_rested` 일회성 플래그를 적용했다.
3. **관절의 단절감:** 단순 부품 캐릭터를 연결된 소매·바지 메시, 17개 본·혼합 스킨 가중치와 4종 클립을 가진 직접 제작 모델로 교체했다. 얼굴·머리카락·재킷·부츠·배낭 디테일을 추가했다.
4. **느린 프레임의 이동 지연:** 프레임 시간을 과하게 잘라 느려지던 이동을, 최대 0.25초를 0.05초 이하 하위 단계로 나누어 처리하도록 수정했다. 벽 통과를 막으면서 느린 프레임에서도 이동 시간을 더 정확하게 반영한다.
5. **불필요한 동적 조명 부담:** 낮 골목의 가로등과 간판마다 추가하던 점광원을 줄였다. 정적 배경 메시를 재질별로 합치고, NPC와 플레이어가 공유하는 스킨 지오메트리를 장면 전환에서 잘못 해제하지 않게 했다.
6. **3D 선택지 UI:** 물체에 해당하는 선택지만 표시하고 단축키 번호를 다시 매겼다. 조사 후 패널을 닫고 완료 표식을 제거하며, 인벤토리·대화상자 중 이동을 중단한다.
7. **초점·종료 안내:** 동적 버튼 갱신 뒤 초점을 복원하고, 종료한 여정에서 다음 행동 아사 경고가 나오던 문구를 고쳤다.
8. **테스트 정면 조건:** 벽에 비스듬히 이동하면 올바르게 미끄러지는데도 완전 정지를 기대하던 조건을 고쳤다. 실제 마우스 조작으로 시점을 벽의 수직 방향에 맞춘 뒤 정면 충돌과 추가 비용이 없음을 검증한다. 실패한 브라우저 컨텍스트도 검사 종료 시 항상 정리한다.

## 배포 상태와 제한

- 현재 클라우드 서버는 새 3D HTML을 제공하며 정상 응답한다. 공개 URL이나 영구 외부 호스팅이 완료된 것은 아니다.
- 사용자가 요청한 **Sites 플러그인은 현재 도구·스킬 검색에서 게시 기능이 제공되지 않았다.** Sites 설치·계정 연결·게시를 자율 실행할 수 있는 도구가 없어 실제 게시 호출이나 공개 주소 발급을 하지 못했다.
- GitHub Pages 워크플로는 준비된 대체 경로다. 원격 push·Pages 활성화·공개 배포 검증은 하지 않았다. 이전 GitHub API 접근은 egress CONNECT 403이었다.
- 설치·재시작 지침은 환경 설정 초안에 저장했다. 초안 검토·저장·환경 게시와 Sites 웹 공개는 서로 다른 작업이다.
- GPU 검증은 SwiftShader다. 실제 모바일 하드웨어·Safari·특정 GPU의 FPS, 전체 월드의 장시간 메모리 사용, Unity 빌드는 검증하지 않았다.
- 관리형 브라우저의 `file://` 정책 차단을 우회하지 않았다. HTTP 실행과 서버 없는 HTML 렌더링은 각각 확인했다.
- 공간 좌표는 새로고침 시 스테이지 진입점으로 돌아온다. HP·허기·자금·아이템·단서·이벤트 진행·난수는 유지한다.
- 캐릭터와 공간은 직접 제작한 스타일화된 프로토타입이다. 대규모 오픈 월드·차량 운전·전투·사실적 지리·Unity WebGL을 구현했다는 의미는 아니다.
